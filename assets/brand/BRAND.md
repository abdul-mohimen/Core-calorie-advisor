# Core Calorie Advisor — Brand Guidelines

## Minimum Size
- **Digital**: The logo mark should never be rendered smaller than **16px x 16px**.
- **Print**: The logo mark should never be rendered smaller than **0.25 inches**.
- **Wordmark**: The full wordmark lockup should never be rendered smaller than **80px wide**.

## Clear Space
- A minimum clear space equal to the height of the inner "dumbbell" must be maintained around the logo on all sides.
- No other graphic elements, typography, or borders should enter this clear space.

## Colors
- **Primary Orange**: `#FF6B1A`
- **Dark Base**: `#0F1115`
- **Light Base**: `#F8F9FA`

## Typography
- The wordmark uses a bold, geometric sans-serif (e.g., *Inter*, *Outfit*, or *Russo One* where available), utilizing tight letter-spacing (-0.02em) for a solid, energetic feel.
